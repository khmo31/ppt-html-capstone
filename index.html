LLM Data Flow
career_agent: LLM이 입력받고 출력하는 데이터 구조

→ INPUT LLM에 전달되는 데이터
// LLM Client → Prompt 구성 system_prompt = """ 당신은 채용공고 분석 AI입니다. 사용자의 입력을 분석하여 적합한 채용공고를 추천합니다. """ user_input = { "message": "경남 지역 공공기관 정규직...", "context": { "index_path": "20_Meta/Facet_Index.json", "facet_keys": [ "education", "hire_type", "ncs", "region" ] } } facet_context = """ [Facet Index] education: 고졸, 대졸, 석사이상, 학력무관 hire_type: 정규직, 무기계약직, 비정규직, 청년인턴 region: 서울, 부산, 대구, 경남, 경기... """ // 실제 LLM 요청 payload { "model": "opencode-go/deepseek-v4-flash", "messages": [ {"role": "system", "content": "system_prompt + facet_context"}, {"role": "user", "content": "user_message"} ], "temperature": 0.3 }
← OUTPUT LLM이 반환하는 데이터
// LLM 응답 → 분석 결과 { "keywords": [ "정규직", "경남", "공공기관", "대졸", "행정직" ], "selected_facets": { "education": "대졸", "hire_type": "정규직", "region": "경남", "ncs": "행정·경영" }, "reasoning": "사용자가 경남 지역의 공공기관...", "suggested_queries": [ "경남 정규직 행정직", "공공기관 대졸 신입" ] } // 이후 Python Scoring Engine이 // LLM 출력 → 실제 공고 점수화 Python { "score": "category_hit_ratio", "threshold": 0.5, "results": [{ "job": "...", "match": 0.75, "facets": {...} }] }

06

3-Stage Matching Engine
LLM 초안 분석 → Facet 분류 → Python 점수화

Stage 1: LLM 분석
Stage 2: Facet 분류
Stage 3: 점수화 추천

🧠 Stage 1 — LLM Initial Analysis

사용자가 입력한 텍스트를 LLM이 분석하여 핵심 키워드와 선호도를 추출. 이 단계에서는 실제 공고를 노출하지 않음 (Hallucination 방지).

사용자 입력: "경남 지역 공공기관에 정규직으로 취업하고 싶어요. 학력은 대졸이고 행정직을 희망합니다." LLM 분석: { keywords: ["경남", "공공기관", "정규직", "대졸", "행정직"], reasoning: "지역+고용형태+학력+NCS축으로 분류 가능" }
모델: deepseek-v4-flash temperature: 0.3

📋 Stage 2 — Facet Selection

LLM 분석 결과를 바탕으로 실제 Facet Index에서 일치하는 분류값을 선택. Python이 키워드 기반으로 검증하여 잘못된 분류를 걸러냄.

LLM 키워드 → Facet 매핑 { "경남" → region: "경남", "정규직" → hire_type: "정규직", "대졸" → education: "대졸", "행정직" → ncs: "행정·경영", "공공기관" → recruitment_type: "신입·경력" }
Python 검증 통과 Facet Index 대조

⚡ Stage 3 — Python Scoring

선택된 Facet 조합을 실제 공고들과 비교하여 점수화. 카테고리 히트 비율(category_hit_ratio) 기반으로 50% 이상 매칭 공고만 최종 추천.

score = "일치한 Facet 수 / 전체 선택 Facet 수" // 예: 5개 Facet 중 4개 일치 매칭 결과 #1: { "title": "경상남도 정규직 행정직", "org": "한국농촌경제연구원", "match": 0.8, // 4/5 = 80% "facets": { "education": "대졸 ✅", "hire_type": "정규직 ✅", "region": "대전 ❌", "ncs": "행정·경영 ✅", "deadline": "2026-06-10 ✅" } }
Threshold: 50% 점수화만 Python 담당

🔄 LLM은 초안 분석만 — 최종 추천은 Python-only로 Hallucination 차단

Pipeline in Detail
전체 Data Flow — 수집부터 최종 추천까지

📥 Collection Pipeline

GitHub Actions (harvest.yml) Trigger: "매일 06:00, 18:00 KST" | "수동 workflow_dispatch" Steps: 1. "Checkout repo" 2. "Setup Python 3.12" 3. "pip install -r job_raw/requirements.txt" 4. "python job_raw/scripts/main.py" ├─ fetcher.py → "공공 API 순회 요청" ├─ formatter.py → "JSON → MD + frontmatter" ├─ writer.py → "00_Raw/ 저장 + index.json 갱신" └─ json_archive → "원본 JSON 보존" 5. "python job_core/scripts/cleanup_expired.py" // 마감일 지난 공고 제거 6. "python job_core/scripts/wiki_generator.py" // Facet Wiki 재생성 7. "git add → commit → push"

🧠 Inference Pipeline

사용자 요청 → Flask Server 1. "POST /api/recommend" body: { "message": "..." } 2. "LLM 분석 요청 (pipeline.py)" ├─ system_prompt = "Facet Index 컨텍스트 + 지시사항" ├─ user_message = "사용자 입력" └─ LLM 응답 = "keywords + selected_facets" 3. "Python Scoring (pipeline.py)" ├─ load Facet Index ├─ for each job: │ score = "count(matching_facets) / total_facets" └─ filter : "score > 0.5" 4. "JSON 응답 반환" response: { "recommendations": [{ "title", "org", "match", "facets", "url" }] } 5. "Frontend 표시" → "카드 UI로 매칭률 정렬 표시"

↻ Update Cycle

⏰ 06:00 KST → "수집 + Wiki 갱신" ⏰ 18:00 KST → "추가 수집" 📊 수동 → "workflow_dispatch 가능" Update Flow: 1. "새 공고 수집 → 00_Raw/ 추가" 2. "만료 공고 제거" 3. "Wiki Facet 재생성" 4. "git push → repo 갱신" 5. "Flask 서버 재시작 없이 자동 반영" // index.json 기반 동적 로딩
