Problem & Goal

⚠️

Problem

공공 채용공고는 기관별로 분산 게시되고, 비정형 데이터라서 직접 비교/분석이 어렵다. 취업자가 조건에 맞는 공고를 찾기 위해 수많은 사이트를 일일이 확인해야 하는 비효율이 발생한다.

🎯

Goal

채용공고를 자동 수집하고,
Facet 기반 위키로 구조화한 뒤,
LLM + Python 점수화로
개인 맞춤형 추천까지 One-Stop으로 제공한다.

Directory Roles

  • ✓ job_raw — 원천 데이터 수집 계층. 공공 API → 정규화 → 마크다운/JSON 저장
  • ✓ job_core — 처리 계층. raw 데이터에서 Facet 위키 생성, 만료 정리
  • ✓ job_career — 서비스 계층. Flask 웹 UI + LLM 추천 + Python 점수화
  • ✓ job_wiki — 결과물 계층. Obsidian 호환 Facet 위키 저장소
  • ✓ .github/workflows — CI/CD. 정기 수집 자동화

Career Recommender

3-Stage Matching Architecture

STAGE 1

LLM Initial Analysis

사용자 입력 → LLM이 키워드/선호도 추출. 추천 기업은 아직 노출하지 않음

→
STAGE 2

Follow-up Selection

Facet 분류 선택. LLM 키워드 + Python 검증으로 분류 확정

→
STAGE 3

Python Scoring

카테고리 히트 기반 점수화. 50% 이상 매칭률 공고만 추천

🧠

LLM Client

OpenCode Go (deepseek-v4-flash)로 키워드 추출 및 분류 판정. Facet Index 읽어 컨텍스트 최적화

⚡

Pipeline

LLM → Python 분리로 비용 절감. LLM은 초안만, 최종 점수는 Python이 담당

🎨

Frontend

Flask 서빙 HTML/CSS/JS. 반응형 UI, 단계별 결과 표시, 분류 선택 인터랙션
